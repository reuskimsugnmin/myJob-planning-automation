# Image Explore (레퍼런스 이미지 비전 분석)

이미지 "읽기"의 단일 소스. 비주얼 모사가 아니라 **화면이 무엇을 어떻게 담는지** 파악하는 게 목적이다.
파일은 쓰지 않는다 — 저장은 `knowledge-base` 스킬(manifest), 분석·문서화는 호출자 스킬이 한다.

## 1. 대상
- `reference.images`(로컬 이미지 파일/디렉토리) + 런타임 인자. `.png` `.jpg` `.jpeg` 등.
- 디렉토리면 `Glob`으로 이미지만 추린다.

## 2. 토큰예산 — 선별·직렬 (중요)
- 이미지 비전은 토큰이 크다. **한 번에 여러 장을 로드하지 않는다.**
- 목표(이번 신규 기능)와 관련성이 높은 이미지를 **선별**하고, **한 장씩 `Read`(비전)로 읽고 요약한 뒤 다음 장**으로 넘어간다(figma 직렬 규율과 동일 철학).

## 3. 추출 대상
- 화면의 **구성요소·라벨·텍스트, 화면 간 플로우 단서, 정보구조/내비게이션, 상태·분기**.
- ⚠️ **비주얼 스타일(색·타이포·컴포넌트 외형) 모사는 목적이 아니다.** 무엇을 보여주고 어떤 순서로 동작하는지에 집중한다(UI 금지/UX 추출 정책은 `reference-research` 가 소유).

## 4. 출처 / 적재
- 모든 관찰에 **이미지 파일 경로**를 인용한다.
- 읽은 이미지는 `source-manifest` 에 type=`image` 로 기록(파일 경로·as_of).

## 원칙
- 출처 없는 단정 금지. 이미지에서 안 보이는 건 추정으로 표시.
- 무차별 대량 로드로 토큰을 낭비하지 않는다(선별·직렬).
