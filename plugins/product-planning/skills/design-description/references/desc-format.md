# 디스크립션 양식 상세 — 오버레이·인포박스 / 개발자 상세 필드 정의 (design-description §4·§4-D)

> `design-description` SKILL.md §4(e)(f)·§4-D의 핀 대상. 본문 형식의 핵심 규칙(제목=요소명·노드/컴포넌트명 금지·(a)역할문장·(b)[항목]형식·(b-1)요소종류별 필수표·(c)Default상태)은 SKILL.md §4 본문에 있고, 여기엔 오버레이/인포박스 상세와 dev 필드 정의를 둔다.

## §4 (e)·(f) — 오버레이 배지 / 인포박스 variant
- **(e) 오버레이 상태 화면(셀렉트 시트·세부안내 시트·팝업, `figma-design` §M) — 배지 = parent + 액션 하위배지.** 오버레이에는 **다음 정수 배지(parent)** 를 부여하고(예 base 1~4 다음 시트=5·팝업=6), **오버레이 안 액션 받는 요소마다 하위 배지(Na/Nb)** 를 단다(예 팝업 상위=6, 닫기=6a, 다시 시도=6b / 시트 항목=5a, 닫기=5b). ★ 닫기(✕)·바깥탭도 **별도 "배지 1"이 아니라 그 오버레이의 하위 배지**(예 5b)다(과거: 오버레이마다 배지 1을 또 달아 중복·고아 발생). parent annotation 본문에 **`[트리거]`·복귀 `[Action]` + `[세부] (Na) 요소: 동작`** 으로 하위배지를 fold. 카운트 불변식: parent는 정수 배지로 카운트, 하위(Na)는 fold(`badge-mechanics.md` §2). base 트리거 요소 본문엔 `→ (N)` 포인터만.
- **(f) 안내 문구 = 인포박스(`figma-design` §M-6) variant 매핑** — `[컴포넌트 상태]`나 역할 문장에 색 의미를 명시: **red=부정/주의**(만료·취소·실패 경고), **blue=긍정**(혜택·완료 안내), **gray=중립 안내**. raw 캡션이 아니라 인포박스임을 전제로 기술.

## §4-D. 개발자 상세 모드 (`--dev-detailed` = 기본 작성 요건) — 각 필드 정의
개발자가 화면만 보고 구현할 수 있게, **작성 시점에** §4-b1 종류별 필수 필드를 채운다(부록이 아니라 **기본 작성 요건** — `--dev-detailed`가 기본이므로 dev 필드는 옵션이 아니다). 표준 라벨 양식 그대로(`[항목]` 단독 줄 + `- 값` 불릿). 각 필드 정의:
- **`[상태]`** — 컴포넌트의 **모든 상태 + 전이 트리거**(default/focus/filled/selected/loading/error/empty/disabled). 단순 enabled/disabled면 §4 `[Default 상태]` 한 줄로 충분, 다상태면 여기서 펼친다. 예: `- Error: 응답 실패 시 테두리 red + 인라인 배너`.
- **`[데이터]`** — 동적 값의 `필드: 타입, 출처, 범위/포맷, 기본값`. 예: `- amount: number(원), 사용자 입력, 1만~300만, 천단위 콤마, 기본 0`.
- **`[인터랙션]`** — 제스처 → 결과 + **이동 화면 + 전달 파라미터**. 예: `- 탭 → P-03 (params: productId, amount, term)`.
- **`[연동]`** — 흐름·분기만(엔드포인트·성공/실패→다음 화면). **데이터 계약·요청/응답 스키마는 적지 말고 `(SDD §x)`로 링크**(중복·비대화 방지).
- **`[엣지/예외]`** — empty·네트워크 오류·타임아웃·권한 거부·overflow·긴 텍스트 잘림.
- **`[수용 기준]`** — Given/When/Then 한 줄 + `(US-n)` 연결.
- **지어내기 금지.** 미정 계산식·엔드포인트·필드명은 **`[미확정 D-n]`** 으로 표시하고 SDD/사용자 결정에 위임(`⛳DECISION`) — 그 `D-n`은 `policy-table.md` 디자인 의사결정 체크리스트에 적재(데이터·API 계약 미정은 SDD C1로). 자료 없는 단정 금지.
- **경계**: UI 상태·인터랙션·카피·검증 시점은 여기, **데이터/API 계약은 SDD**(`sdd-author`+`tech-registry`). 디스크립션은 SDD를 링크만.
